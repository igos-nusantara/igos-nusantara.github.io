Bayu desktop environment

One desktop. Two toolkits. No seams.

BAYU is the Wayland desktop environment at the centre of IGN 26, built component by component — compositor, shell, session, file manager, settings and terminal — so that every window shares one visual language instead of three. In the nightly image you can also choose the layout: a Dock with a top bar for the menus, or one Panel along the bottom. Settings > Desktop switches between them at once.

Compositor & shell

A Wayland compositor with its own panel, dock, launcher and overview — no GNOME or KDE shell underneath.

Session & display manager

A matching greeter and session manager, so the look starts at the login screen and never breaks.

File manager

Tabs, split view, archive handling and Flatpak-aware Open With, in the same window chrome as everything else.

Settings

Wi-Fi, Bluetooth, display, sound, keyboard, dock and appearance in one searchable app.

Terminal

Themed to follow the system accent and light/dark mode automatically.

Bayu Store

Flathub and F-Droid in a single catalogue — install, update and remove from one place.

Nabau installer

A guided, eight-step installer that works for any systemd Linux distribution.

Lapis runtime

Android apps as real Wayland windows, powered by a kernel with binder support.

A wallpaper that follows the day

The default wallpaper is a set of four pictures of Mount Bromo: morning, day, evening and night. It changes by itself with sunrise and sunset in your time zone, so WIB, WITA and WIT each change at their own times. You can make it follow light and dark mode instead. A second set, a forest, is in Settings > Wallpaper.

Pitaloka design system

One source of truth for GTK 4 and Qt 6.

Every colour, radius, font step and elevation in BAYU comes from one file: tokens.json. From it, Pitaloka generates a stylesheet for each toolkit, so a GTK 4 app and a Qt 6 app sitting side by side are pixel-consistent — same card radius, same accent, same focus ring.

Lapis · Android on Linux

Android apps as ordinary Wayland windows.

Lapis boots a LineageOS-based Android image inside a systemd-nspawn container running on your own kernel. No virtual machine, no LXC, no Python — a single static Go binary and a handful of systemd units. Each Android app opens as its own window, alongside your Linux apps, in the same dock and the same alt-tab.

  • Google Play, with optional ARM translation
  • GPU acceleration through host render nodes (Mesa)
  • Audio routed over PipeWire or PulseAudio
  • Clipboard sync, notifications and desktop menu entries
  • Automatic freeze on suspend, so nothing drains in the background
  • Phone and tablet UI layouts with adjustable window sizes

How it runs

Android apps

Each app is a separate Wayland window

LineageOS image

Booted inside a systemd-nspawn container

Lapis · single static Go binary

Pure-Go binder · nftables NAT over netlink · DHCP + DNS forwarder · raw BPF seccomp · minimal PID-1 shim

Host kernel with binder support

Your kernel. No hypervisor, no second scheduler.

  • amd64 / arm64

Nabau · universal installer

An installer any Linux distribution can ship.

Nabau is the guided installer introduced with IGN 26, and it is deliberately distribution-agnostic. Eight plain-language steps, a full review before a single byte is written, GPG-verified packages and Secure Boot support — nothing in the flow is tied to IGOS Nusantara.

GPG-verified packages

Secure Boot stays on, and every package is checked before it lands on disk.

Your data is kept

Only the space you choose on the destination is touched. Everything else is left alone.

Escape hatches

F1 opens help, F12 drops to a console. The installer never hides what it is doing.

Twelve languages

Also in this release

The parts you only notice when they are missing.

Twelve interface languages

Indonesian, Javanese, Sundanese, Malay, Chinese, Japanese, Korean, Spanish, French, German, Portuguese and Russian — translated across the shell, settings, store and installer.

Apple hardware support

Keyboard and trackpad quirks, SMC drivers and sensible Command-key defaults, so a MacBook behaves like a MacBook.

Wi-Fi out of the box

Drivers for the Broadcom chipsets in older MacBooks, are on the ISO. The nightly image adds common Realtek, MediaTek, Ralink and Atheros USB adapters. No cable needed to get online during install.

Built entirely in containers

Every package and image is produced with Podman in CI, so a build is reproducible and auditable from the first commit.

Live ISO, no install required

Boot the image from a USB stick and use the finished system straight away. Install to disk later from the same session — or never, and keep running it live.

GPL-3.0 and BSD-3-Clause

Dual-licensed GPL-3.0 and BSD-3-Clause. Every component is free software, with the full source and build recipe published. Nothing is hidden.

Printers found by themselves

Network printers and driverless USB printers are set up as soon as they appear. Settings > Printers prints a test page, sets the default and shows the jobs. Scanners work too. In the nightly image now.

Updates at a restart

Settings > System Update downloads the system's updates in the background and installs them when you restart. App updates are in Bayu Store. In the nightly image now.

Hardware tools included

lsusb, lspci, lshw, hwinfo, sensors, smartctl, nvme, iw and ethtool are there, so you can see what hardware you have and report a problem. In the nightly image now.
