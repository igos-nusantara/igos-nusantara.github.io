IGN 26 Docs

Getting started

IGN 26 is a Linux distribution built in Indonesia. These guides take you from downloading it to using it every day.

IGN 26 comes as a live image. You write it to a USB stick, start your computer from it, and use the full desktop without touching your disk. If you want to keep it, the installer puts it on your disk in a few minutes.

What you need

PartMinimum
Processor64-bit x86 (amd64)
Memory4 GB. 8 GB if you want Android apps.
Disk20 GB free
FirmwareUEFI. Almost every computer made since 2012 has it.
USB stick2 GB or larger. Everything on it will be erased.
