Files and Terminal

Work with files, open system folders as an administrator, and use the terminal and the tools that come with it.

Open as Administrator, the Terminal menu button, the command-line tools and the shell shortcuts are in the nightly image.

Files

Open Files from the dock. The sidebar shows your folders and drives. When Android is on, Android in the sidebar holds the files of your Android apps, such as downloads and photos.

Copying and moving to a Windows drive (NTFS) works the same as on any other drive.

Open as Administrator

Only an administrator can change system folders such as /etc.

  1. Go to the folder.

  2. Click the menu button in the title bar, next to the search button, and choose Open as Administrator.

  3. Type your password.

  4. A second window opens, titled Files (Administrator). Changes made there are made as the administrator. You can copy and move between it and your other windows as usual.

Clicking a folder in the sidebar that only an administrator may open does the same. Administrator access ends when you close Files.

In the administrator window you can delete or change system files. Be careful.

Terminal

Open Terminal from the dock. Click + in the title bar for a new tab.

To split a tab, click the menu button next to +, or right-click the title bar, and choose Split Right or Split Down. This also works while a program such as htop or mc is using the mouse. To close a pane, right-click inside it and choose Close Pane.

Command-line tools

These tools are already installed:

ForCommands
Codegit
Editing filesvim, nano
Downloadingwget, curl
Processes and disk usehtop, btop, iotop, ncdu, tree
Networkdig, host, traceroute, mtr, whois
Hardwarelsusb, lspci, lshw, sensors, smartctl and more, see Hardware
Othertmux, fastfetch, 7z, bc, pip, strace

Manual pages are installed too: run man followed by the command, for example man tar.

Shortcuts in the shell

The terminal comes with a colored prompt and these short commands:

TypeTo
llList files with details, folders first
.. and ...Go up one or two folders
ex fileExtract an archive: zip, tar.gz, tar.xz, 7z, rar and more
updateUpdate the system (sudo dnf update)
install nameInstall a package (sudo dnf install)
search wordLook for a package (dnf search)
myipShow your public IP address
fastfetchShow the system summary with the IGN logo

rm, cp and mv ask before they delete or overwrite a file. To change any of this, add your own lines to ~/.bashrc.

tmux

Run tmux to keep several shells in one window. The prefix key is Ctrl+A: press it, let go, then press the next key.

KeysTo
Ctrl+A, then vSplit side by side
Ctrl+A, then hSplit top and bottom
Alt+arrow keysMove between panes
Ctrl+A, then rLoad the configuration again

The mouse works in tmux: click a pane, drag a border, scroll back. Your own ~/.tmux.conf is read after the system one.
