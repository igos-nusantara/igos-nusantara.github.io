Dokumentasi IGN 26

Unduh dan tulis ke flashdisk

Unduh image IGN 26, lalu tulis ke flashdisk supaya komputer bisa dinyalakan dari situ.

Menulis image akan menghapus semua isi flashdisk. Pindahkan dulu berkas yang ingin Anda simpan.

Unduh image

Image yang tersedia saat ini adalah IGN 26 Beta 6. Ukurannya sekitar 1,3 GB.

Unduh lewat peramban: ign26-bayu-beta6.iso. Atau lewat terminal:

curl -LO https://r2.igos-nusantara.or.id/iso/beta/ign26-bayu-beta6.iso

Ada juga image nightly yang dibangun setiap hari dari kode terbaru: ign26-bayu-harian-latest.iso. Pakai ini untuk mencoba perubahan sebelum beta berikutnya. Bisa saja ada bug baru.

Menulis di Linux

Colokkan flashdisk, lalu lihat daftar disk:

lsblk -d -o NAME,SIZE,MODEL

Kenali flashdisk dari ukuran dan modelnya, misalnya sdb. Pastikan itu bukan disk tempat sistem Anda berjalan.

Tulis image-nya. Ganti sdX dengan nama yang Anda temukan:

sudo dd if=ign26-bayu-beta6.iso of=/dev/sdX bs=4M status=progress oflag=sync

Flashdisk siap dipakai setelah prompt muncul lagi.

Menulis di Windows atau macOS

Pakai balenaEtcher. Gratis, dan cara pakainya sama di kedua sistem.

  1. Buka balenaEtcher, klik Flash from file, lalu pilih berkas .iso yang sudah diunduh.

  2. Klik Select target dan pilih flashdisk Anda.

  3. Klik Flash! dan tunggu sampai muncul tulisan bahwa proses selesai.

Di Windows Anda juga bisa memakai Rufus. Jika ditanya cara menulis image, pilih DD Image mode.

Atau coba di mesin virtual

Image ini juga bisa dijalankan di GNOME Boxes, virt-manager, atau VirtualBox. Beri mesinnya memori minimal 4 GB dan disk 25 GB, lalu aktifkan UEFI. Di VirtualBox, pengaturannya ada di Settings → System → Enable EFI.

Berikutnya: menjalankan sesi live.
