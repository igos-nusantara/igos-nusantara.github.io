Dokumentasi IGN 26

Aplikasi Android

Aplikasi dari F-Droid berjalan di Lapis, sistem Android yang berjalan di samping desktop. Setiap aplikasi terbuka di jendelanya sendiri.

Sebelum mulai

  • Disarankan memori 8 GB. Jika kurang, biarkan kompresi memori aktif (lihat Memori).
  • Mengaktifkan Android mengunduh sekitar 1,3 GB, sekali saja. Pakai koneksi yang cepat.
  • Anda perlu kata sandi administrator.

Mengaktifkan Android

  1. Di Bayu Store, klik Pasang pada aplikasi F-Droid mana pun. Bayu Store bertanya Aktifkan aplikasi Android? Klik Aktifkan.

  2. Ketik kata sandi Anda lalu tekan Enter.

  3. Tunggu unduhannya selesai. Unduhan berjalan di latar belakang, dan Bayu Store belum menampilkan kemajuannya. Dengan koneksi 10 Mbit/s butuh sekitar 20 menit.

  4. Setelah itu Android menyala untuk pertama kali, sekitar satu menit. Lalu klik Pasang lagi pada aplikasinya.

  5. Jika tombolnya berubah menjadi Buka, klik. Aplikasi Android terbuka di jendelanya sendiri, sama seperti aplikasi lain.

Android juga bisa diaktifkan dari Pengaturan toko, di bagian Aplikasi Android.

Jika unduhan berhenti

Image Android diunduh dari mirror SourceForge, yang kadang lambat. Jika Bayu Store menampilkan Aplikasi Android tidak dapat diaktifkan, buka Terminal lalu jalankan:

sudo lapis init -type VANILLA

Perintah ini melanjutkan unduhan dari titik terakhir dan mencoba mirror lain dengan sendirinya. Setelah selesai, pasang lagi aplikasinya dari Bayu Store.

Jika tertulis Android tidak berjalan

Android butuh sekitar satu menit untuk menyala setelah Anda masuk atau mengaktifkannya. Jika Bayu Store menampilkan Android container is not running atau Can't find service: package, tunggu satu menit lalu klik Pasang lagi.

Kontroler game

Kontroler game di Android ada di image nightly.

Kontroler game (gamepad), lewat USB atau Bluetooth, langsung sampai ke Android begitu dicolokkan atau dipasangkan, jadi game dan emulator menemukannya seperti di ponsel. Headset, mouse, dan keyboard Bluetooth tidak butuh pengaturan tambahan: suara Android keluar lewat desktop, dan mouse serta keyboard berfungsi seperti di aplikasi lain.

Aplikasi khusus ARM

Sebagian aplikasi Android hanya dibuat untuk prosesor ponsel (ARM). Aplikasi ini disembunyikan secara bawaan. Untuk menampilkannya, aktifkan Tampilkan aplikasi yang hanya dibuat untuk ARM di Pengaturan toko. Aplikasi ini berjalan lewat penerjemah, jadi lebih lambat dan sebagian tidak berjalan.
