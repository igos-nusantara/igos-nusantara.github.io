Install with Nabau

Nabau puts IGN 26 on your disk in eight steps. Nothing is written until you click Begin installation in step 7.

The automatic layout erases the whole disk you choose. Back up your files before you start.

Nabau opens by itself in the live session. If you closed it, click its icon in the dock.

The screenshots show Nabau in English. For now Nabau stays in Indonesian after step 1, even if you choose English (issue #42). The buttons are in the same place, and the installed system uses the language you chose.

The eight steps

  1. Language. Choose the language for the installed system and a regional format. The format decides how dates, numbers and money look. The Preview box shows an example. Click Continue.

  2. Network. A connection is optional, but it lets Nabau set the clock. Wired connections connect by themselves. Host name is your computer's name on the network; you can leave it.

  3. Localization. Choose the keyboard layout you type with. Type a few letters in Test the layout to check it. The time zone is found from your network; change Region and City if it is wrong.

  4. Destination. Select the disk. Keep Automatic unless you know which partitions you want. Turn on Encrypt my data if the computer could be lost or stolen: you will then type a password every time it starts.

  5. Software. IGN 26 Desktop is the desktop you are using now. The add-ons on the right are optional, and you can install them later with dnf.

  6. Account. Type your full name; the user name fills in by itself. Type a password twice. Leave Make this user an administrator on, so you can install software and change system settings.

  7. Review. Check the summary. Click Edit on a card to change it. When it is right, click Begin installation. This is the moment the disk is erased.

  8. Install. Wait until it finishes. On our test machine it took under two minutes; a slow USB stick or disk takes longer.

Finish and restart

  1. When you see You're all set, take out the USB stick, then click Restart now.

  2. The sign-in screen shows your name. Type your password and press Enter.

  3. A welcome window offers a short tour of the desktop. Click Start the tour, or Skip.

Get the latest updates

The image can be a few days old. Open Terminal from the dock and run:

sudo dnf upgrade
