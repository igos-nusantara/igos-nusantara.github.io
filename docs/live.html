Start the live session

Start your computer from the USB stick and try IGN 26 without installing it.

  1. Plug in the USB stick and turn the computer on. Straight away, press the key that opens the boot menu. It is often F12, F11, F9 or Esc. The first screen usually tells you which one.

  2. Choose the USB stick from the list.

  3. The IGN 26 menu appears. Press Enter on Start IGOS Nusantara 26, or wait three seconds and it starts by itself.

  4. The desktop starts and opens the installer, Nabau. You can install now, or close Nabau and look around first. Its icon stays in the dock.

The live session starts in Indonesian. You choose your language in the first step of Nabau, and the installed system uses it.

What works in the live session

Everything: Files, Terminal, Settings, Bayu Store and the network. Nothing is saved to your disk. Files you create and apps you install are gone when you restart.

If the screen stays black

Restart, and in the menu choose Start IGOS Nusantara 26 (basic graphics). It uses a simpler display driver that works on more graphics cards.

The Troubleshooting menu

Troubleshooting in the boot menu has two more ways to start:

  • verbose prints every message while the system starts, so you can see where it stops.
  • without the Broadcom wl driver is for computers with Broadcom Wi-Fi that stop while starting.
