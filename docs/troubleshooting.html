Troubleshooting

Common problems and what to do about them.

The computer does not start from the USB stick

  • Open the boot menu with the right key (often F12, F11, F9 or Esc) and pick the stick by hand.
  • Try another USB port, preferably one directly on the computer.
  • Write the stick again. On Windows, use DD Image mode in Rufus, or use balenaEtcher.

The screen stays black

Restart and choose Start IGOS Nusantara 26 (basic graphics) in the boot menu.

Starting stops partway

In the boot menu, open Troubleshooting and choose the verbose entry. The last lines on screen show where it stops. If your computer has Broadcom Wi-Fi, try the entry without the Broadcom wl driver.

Nabau stays in Indonesian after I choose English

This is a known problem (issue #42). The installed system still uses the language you chose. Every step has its buttons in the same place in every language, so you can follow Install with Nabau as it is.

Android apps could not be turned on

Usually the 1.3 GB download stopped. Run sudo lapis init -type VANILLA in Terminal; it continues where it stopped. See Android apps.

Reporting a bug

Open an issue at github.com/igos-nusantara/bayu/issues. Say what you did, what you expected and what happened instead, and attach a screenshot if you can.
