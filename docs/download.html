IGN 26 Docs

Download and write to USB

Download the IGN 26 image and put it on a USB stick you can start your computer from.

Writing the image erases everything on the USB stick. Copy off anything you want to keep first.

Download the image

The current image is IGN 26 Beta 6. The file is about 1.3 GB.

Download it in your browser: ign26-bayu-beta6.iso. Or in a terminal:

curl -LO https://r2.igos-nusantara.or.id/iso/beta/ign26-bayu-beta6.iso

There is also a nightly image, built every day from the newest code: ign26-bayu-harian-latest.iso. Use it to try changes before the next beta. It may have new bugs.

Write it on Linux

Plug in the USB stick, then list your disks:

lsblk -d -o NAME,SIZE,MODEL

Find the stick by its size and model, for example sdb. Make sure it is not the disk your system runs from.

Write the image. Replace sdX with the name you found:

sudo dd if=ign26-bayu-beta6.iso of=/dev/sdX bs=4M status=progress oflag=sync

The stick is ready when the prompt comes back.

Write it on Windows or macOS

Use balenaEtcher. It is free and works the same on both.

  1. Open balenaEtcher and click Flash from file. Choose the .iso file you downloaded.

  2. Click Select target and choose your USB stick.

  3. Click Flash! and wait until it says the flash is complete.

On Windows you can also use Rufus. If it asks how to write the image, choose DD Image mode.

Or try it in a virtual machine

You can start the image in GNOME Boxes, virt-manager or VirtualBox instead of a USB stick. Give the machine at least 4 GB of memory and a 25 GB disk, and turn on UEFI. In VirtualBox that is Settings → System → Enable EFI.
